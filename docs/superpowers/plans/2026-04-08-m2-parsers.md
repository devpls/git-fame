# M2 Parsers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the two streaming parsers that turn git output into typed events: `parseBlamePorcelain` consumes `git blame --line-porcelain` output and yields one `BlameLine` per content line; `parseLogNumstat` consumes `git log --numstat` output and yields one `LogCommit` per commit. These are the heart of correctness for node-fame — the pipeline's correctness depends on them.

**Architecture:** Both parsers are `async function*` generators (the only technically valid form for streaming parsers — arrow generators do not exist). Each reads a `NodeJS.ReadableStream` line-by-line via `readline`, runs a small state machine, and yields typed events. Unit tests drive them via programmatically-built fixture strings (exact byte control, no binary files, diffable). Each parser also gets a single integration test that spawns real git on a `buildRepo` fixture and feeds the output through the parser — a sanity check against format drift.

**Tech Stack:** TypeScript 6 (strict + `noUncheckedIndexedAccess`), Node 20+ (`node:readline`, `node:stream`), vitest 4 for testing.

**Commit style:** Single-line messages, plain English, no semantic prefix, no `Co-Authored-By` trailer. See `CLAUDE.md`.

**Context for implementer:** The canonical spec is `docs/superpowers/specs/2026-04-08-node-fame-design.md` — read **Section 2** (public types), **Section 3** (parser component descriptions + data flow), and **Section 4** (error handling — parsers throw on malformed input; the pipeline layer wraps parser throws into per-file warnings later).

**M1 is complete.** The project has typed errors under `src/errors/`, git wrappers under `src/internal/git/` (with `spawnGit`, `collectStream`, `isGitRepo`, `resolveRev`, `resolveRange`, `listTrackedFiles`, `assertGitInstalled`), and the `buildRepo` test helper under `tests/helpers/`. All 48 M1 tests are green. Refactor to one-export-per-file + colocated tests + Angular-style naming is complete. This plan continues under those conventions.

**Conventions reminder (see `CLAUDE.md` for full):**

- **One public export per file.** Types colocate with their single function.
- **Generators are the only `function*` / `async function*` in the codebase.** Everything else is arrow.
- **Explicit return types on exported functions.** Parsers return `AsyncGenerator<T>`.
- **ESM imports with `.js` extensions**, relative only (no path aliases).
- **Named exports only.** No default exports.

The builder takes a structured list of blame entries and returns a single string in exactly the format that `git blame --line-porcelain` produces. Each entry represents one content line with its header block.

`git blame --line-porcelain` emits, for each blamed line, a header line (`<sha> <orig> <final> [<count>]`), several metadata lines (`author <name>`, `author-mail <<email>>`, `author-time <unix>`, `author-tz`, `committer <name>`, `committer-mail`, `committer-time`, `committer-tz`, `summary`), an optional `boundary` marker, a `filename <path>` line, and finally a tab-prefixed content line. The group-count field in the header appears only on the first line of a run from the same commit; subsequent lines within the run omit it. The `boundary` line is present only when the commit is the oldest ancestor visible in the analysis range.

```ts
export interface BlameFixtureEntry {
  sha: string;
  origLine: number;
  finalLine: number;
  groupCount?: number;
  authorName: string;
  authorMail: string;
  authorTime: number;
  committerName?: string;
  committerMail?: string;
  committerTime?: number;
  summary: string;
  boundary?: boolean;
  filename: string;
  content: string;
}

const formatEntry = (entry: BlameFixtureEntry): string => {
  const headerSuffix = entry.groupCount !== undefined ? ` ${String(entry.groupCount)}` : '';
  const lines = [
    `${entry.sha} ${String(entry.origLine)} ${String(entry.finalLine)}${headerSuffix}`,
    `author ${entry.authorName}`,
    `author-mail <${entry.authorMail}>`,
    `author-time ${String(entry.authorTime)}`,
    `author-tz +0000`,
    `committer ${entry.committerName ?? entry.authorName}`,
    `committer-mail <${entry.committerMail ?? entry.authorMail}>`,
    `committer-time ${String(entry.committerTime ?? entry.authorTime)}`,
    `committer-tz +0000`,
    `summary ${entry.summary}`,
  ];
  if (entry.boundary === true) {
    lines.push('boundary');
  }
  lines.push(`filename ${entry.filename}`);
  lines.push(`\t${entry.content}`);
  return lines.join('\n');
};

export const buildBlameFixture = (entries: BlameFixtureEntry[]): string => {
  return entries.map(formatEntry).join('\n') + '\n';
};
```

```ts
export interface LogFixtureFile {
  added: number | '-';
  deleted: number | '-';
  path: string;
}

export interface LogFixtureCommit {
  sha: string;
  authorName: string;
  authorMail: string;
  authorTime: number;
  files: LogFixtureFile[];
}

const formatCommit = (commit: LogFixtureCommit): string => {
  const header =
    `${commit.sha}\x00${commit.authorName}\x00${commit.authorMail}\x00` + String(commit.authorTime);
  const fileLines = commit.files.map((f) => `${String(f.added)}\t${String(f.deleted)}\t${f.path}`);
  return [header, ...fileLines].join('\n') + '\n';
};

export const buildLogFixture = (commits: LogFixtureCommit[]): string => {
  if (commits.length === 0) {
    return '';
  }
  return commits.map(formatCommit).join('\n');
};
```

## Task 3: `parseBlamePorcelain` — happy path

**Files:**

- Create: `src/internal/parse/parse-blame-porcelain.ts`
- Create: `src/internal/parse/parse-blame-porcelain.test.ts`

Generator that consumes a `NodeJS.ReadableStream` of `git blame --line-porcelain` output and yields one `BlameLine` per content line. Must use `async function*` (arrow generators do not exist — this is the only place the `function` keyword appears in new code).

### State machine

- Start with `state = null` (no partial entry in progress).
- Each line from the stream is classified by prefix:
  - **Content line** (starts with `\t`): finalise the current `state` into a `BlameLine`, yield it, reset `state = null`.
  - **Header line** (matches `^[0-9a-f]{40} \d+ \d+(?: \d+)?$`): begin a new entry — set `state = { sha, isBoundary: false }`.
  - **Metadata line** (starts with `author `, `author-mail `, `author-time `, or is exactly `boundary`): fill in the corresponding field on `state`.
  - **Other lines** (`author-tz`, `committer-*`, `summary`, `filename`, `previous`): ignored.
- At end-of-stream, if `state` is non-null, the last block was truncated — throw.
- If a content line arrives before `state` has `sha`, `authorName`, `authorMail`, `authorTime` all set, throw.
- If a header line arrives while `state` is non-null (previous entry never saw its content line), throw.

The parser throws on malformed input. The pipeline layer (M3+) will wrap parser throws into per-file warnings.

```ts
import { createInterface } from 'node:readline';

export interface BlameLine {
  sha: string;
  authorName: string;
  authorMail: string;
  authorTime: number;
  line: string;
  isBoundary: boolean;
}

interface PartialBlameLine {
  sha: string;
  authorName?: string;
  authorMail?: string;
  authorTime?: number;
  isBoundary: boolean;
}

const HEADER_REGEX = /^([0-9a-f]{40}) \d+ \d+(?: \d+)?$/;

const stripAngleBrackets = (mail: string): string => {
  if (mail.startsWith('<') && mail.endsWith('>')) {
    return mail.slice(1, -1);
  }
  return mail;
};

// eslint-disable-next-line func-style -- generators must use the function keyword
export async function* parseBlamePorcelain(
  stream: NodeJS.ReadableStream,
): AsyncGenerator<BlameLine> {
  const rl = createInterface({ input: stream, crlfDelay: Infinity });
  let state: PartialBlameLine | null = null;

  for await (const raw of rl) {
    if (raw.startsWith('\t')) {
      if (
        state === null ||
        state.authorName === undefined ||
        state.authorMail === undefined ||
        state.authorTime === undefined
      ) {
        throw new Error('parseBlamePorcelain: content line before complete header block');
      }
      yield {
        sha: state.sha,
        authorName: state.authorName,
        authorMail: state.authorMail,
        authorTime: state.authorTime,
        line: raw.slice(1),
        isBoundary: state.isBoundary,
      };
      state = null;
      continue;
    }

    const headerMatch = HEADER_REGEX.exec(raw);
    if (headerMatch !== null) {
      if (state !== null) {
        throw new Error('parseBlamePorcelain: header line arrived before previous entry finished');
      }
      const sha = headerMatch[1] ?? '';
      state = { sha, isBoundary: false };
      continue;
    }

    if (state === null) {
      throw new Error(`parseBlamePorcelain: unexpected line outside of a block: ${raw}`);
    }

    if (raw.startsWith('author ')) {
      state.authorName = raw.slice('author '.length);
    } else if (raw.startsWith('author-mail ')) {
      state.authorMail = stripAngleBrackets(raw.slice('author-mail '.length));
    } else if (raw.startsWith('author-time ')) {
      state.authorTime = Number(raw.slice('author-time '.length));
    } else if (raw === 'boundary') {
      state.isBoundary = true;
    }
    // committer-*, author-tz, summary, filename, previous are intentionally ignored.
  }

  if (state !== null) {
    throw new Error('parseBlamePorcelain: unexpected end of stream in the middle of a block');
  }
}
```

## Task 6: `parseLogNumstat` — happy path

**Files:**

- Create: `src/internal/parse/parse-log-numstat.ts`
- Create: `src/internal/parse/parse-log-numstat.test.ts`

Generator that consumes `git log --pretty=format:%H%x00%an%x00%ae%x00%at --numstat` output and yields one `LogCommit` per commit.

### State machine

- Each commit is one header line (4 NUL-separated fields: `<sha>`, `<name>`, `<email>`, `<unix-time>`) followed by zero or more file lines (`<added>\t<deleted>\t<path>`). Commits are separated by a blank line.
- A line containing `\x00` → commit header. If a previous commit is in progress, emit it first, then start a new commit.
- A line matching `^(\d+|-)\t(\d+|-)\t.+$` → file entry, add to current commit's files. Binary files use `-` for both counts; store them as `0`/`0` in the output (the pipeline later distinguishes binary via content-type checks, not via numstat counts).
- An empty line → skip (it's the commit separator).
- End-of-stream → emit the current commit if any.
- Malformed lines (not a header, not a file, not empty) → throw.

```ts
import { createInterface } from 'node:readline';

export interface LogFileChange {
  path: string;
  added: number;
  deleted: number;
}

export interface LogCommit {
  sha: string;
  authorName: string;
  authorMail: string;
  authorTime: number;
  files: LogFileChange[];
}

const NUMSTAT_REGEX = /^(\d+|-)\t(\d+|-)\t(.+)$/;

const parseCount = (value: string): number => (value === '-' ? 0 : Number(value));

// eslint-disable-next-line func-style -- generators must use the function keyword
export async function* parseLogNumstat(stream: NodeJS.ReadableStream): AsyncGenerator<LogCommit> {
  const rl = createInterface({ input: stream, crlfDelay: Infinity });
  let current: LogCommit | null = null;

  for await (const raw of rl) {
    if (raw.length === 0) {
      continue;
    }

    if (raw.includes('\x00')) {
      if (current !== null) {
        yield current;
      }
      const parts = raw.split('\x00');
      if (parts.length !== 4) {
        throw new Error(
          `parseLogNumstat: expected 4 NUL-separated header fields, got ${String(parts.length)}`,
        );
      }
      const sha = parts[0] ?? '';
      const authorName = parts[1] ?? '';
      const authorMail = parts[2] ?? '';
      const authorTimeStr = parts[3] ?? '0';
      current = {
        sha,
        authorName,
        authorMail,
        authorTime: Number(authorTimeStr),
        files: [],
      };
      continue;
    }

    const numstatMatch = NUMSTAT_REGEX.exec(raw);
    if (numstatMatch !== null) {
      if (current === null) {
        throw new Error('parseLogNumstat: file entry before any commit header');
      }
      const addedStr = numstatMatch[1] ?? '0';
      const deletedStr = numstatMatch[2] ?? '0';
      const path = numstatMatch[3] ?? '';
      current.files.push({
        path,
        added: parseCount(addedStr),
        deleted: parseCount(deletedStr),
      });
      continue;
    }

    throw new Error(`parseLogNumstat: unrecognised line: ${raw}`);
  }

  if (current !== null) {
    yield current;
  }
}
```
